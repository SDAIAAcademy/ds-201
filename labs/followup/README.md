# Follow-up task: an inference brief on an open table

Within two weeks of the capstone day, write one more inference brief, this time on real open
data. The task is tracked: your trainer records the link and gives written feedback.

## The task

1. Choose one table from the national Open Data Platform, <https://open.data.gov.sa/en/home>,
   that has at least one numeric column and at least one grouping column (a region, a year, a
   category). Note the dataset's title, publisher, date and licence as the platform states them.
2. Write a question a manager could ask of it, and its estimand.
3. Answer with the five parts of the course: an estimate, an interval, a test, an effect size
   and the limits. If the table is a complete count and not a sample, say so: then there is no
   sampling error to put an interval around, and your brief explains what uncertainty remains
   (measurement, definitions, change over time).
4. State the resampling unit and why. Report how many comparisons you ran.

## What you hand in

A link to a public repository with a brief of at most two pages, the notebook that reruns from
the downloaded table with a fixed seed, and a README that cites the dataset by title, publisher
and address, with its licence.

## Rules

- Use only data that the platform publishes as open. Do not combine it with any other source in
  a way that could identify a person.
- Report at the level the table is published at, or coarser.
- An assistant may be used; say in the README where you used one.
